StockFlow AI Desktop Application - Release v1.0.0
==============================================================================

Product Name : StockFlow AI Desktop
Version      : 1.0.0
Publisher    : StockFlow AI Team
Architecture : Windows x64 / ia32
Backend API  : http://127.0.0.1:8000/api/

------------------------------------------------------------------------------
1. SYSTEM REQUIREMENTS & PREREQUISITES
------------------------------------------------------------------------------
- Operating System : Windows 10 / Windows 11 (64-bit / 32-bit)
- RAM              : 4 GB Minimum (8 GB Recommended)
- Disk Space       : 500 MB Free Space
- Backend Service  : StockFlow AI Django REST API Server running on port 8000

------------------------------------------------------------------------------
2. INSTALLATION INSTRUCTIONS
------------------------------------------------------------------------------
1. Run 'StockFlow-AI-Setup.exe' as Administrator.
2. Select your installation folder (Default: C:\Program Files\StockFlow AI Desktop).
3. Check options to create Start Menu and Desktop Shortcuts.
4. Click 'Install' and wait for setup to finish.
5. Launch 'StockFlow AI Desktop' from Desktop or Start Menu.

------------------------------------------------------------------------------
3. DEFAULT AUTHENTICATION CREDENTIALS
------------------------------------------------------------------------------
- Superuser Username : admin (or prod_admin)
- Password           : admin123
- API Base URL       : http://127.0.0.1:8000/api/

------------------------------------------------------------------------------
4. UNINSTALLATION
------------------------------------------------------------------------------
To uninstall, navigate to Windows Control Panel -> Apps & Features -> Select
'StockFlow AI Desktop' -> Click Uninstall.
Note: Desktop client uninstallation will NOT delete server-side business data.
